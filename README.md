# Акт работ — Android-приложение

Офлайн-журнал заказов с выгрузкой акта за месяц в DOCX. Работает без интернета, без разрешений, Android 10+.

## Собрать APK, вариант 1: GitHub (без Android Studio)
1. Создайте приватный репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Вкладка **Actions** → workflow «Собрать APK» запустится сам (или нажмите *Run workflow*).
3. Через ~3–4 минуты откройте запуск → внизу **Artifacts** → скачайте `AktRabot-apk` (внутри `app-debug.apk`).

## Собрать APK, вариант 2: Android Studio
File → Open → эта папка → дождаться синхронизации → Build → Build App Bundle(s) / APK(s) → Build APK(s).
Файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Установить на телефон
Перекинуть APK на телефон (Telegram «Избранное», почта, кабель) → открыть → разрешить установку из этого источника → Установить.
Play Protect может предупредить о неизвестном разработчике — это нормально для собственной сборки.

## Где что лежит
- `app/src/main/assets/index.html` — весь интерфейс, логика и генератор DOCX (можно открыть в браузере на компьютере для проверки).
- `app/src/main/java/ru/akt/app/MainActivity.java` — хранение записей и сохранение файла в «Загрузки».

Проект подписывается постоянным ключом `app/akt.keystore`, поэтому новые версии ставятся поверх старой и записи сохраняются. Не теряйте этот файл. Удаление приложения стирает записи.
